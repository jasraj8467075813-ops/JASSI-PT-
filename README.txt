RC ESPORTS Points Table Generator
=================================

Files:
- index.html: application layout
- style.css: original embedded styles
- script.js: original embedded application logic

How to run:
1. Keep all three files in the same folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Upload a clean leaderboard template image.
4. Enter team names and match ranks/kills.
5. Download the generated PNG.

Notes:
- Bootstrap, Font Awesome, and Google Fonts are loaded from their CDNs,
  so an internet connection is needed for those external assets.
- Data is stored in this browser's LocalStorage.
- This is a separated reconstruction of the uploaded source, not a new
  backend-enabled application.
